# Evidence runs

This area stores reproducibility records and audit artifacts. It is **not a current SCAP-NG Assessment library** and should not be used as the starting point for authoring or for the VS Code editor.

Historical conversion experiments and superseded content packages are kept in the private research repository rather than promoted here. The current public authoring baseline is the [SCAP-NG 0.4 schema and curated examples](https://github.com/vanderpol/scap-ng).

For new evidence, use a stable run identifier and include a manifest satisfying the [evidence contract](../EVIDENCE-CONTRACT.md). Clearly identify the source commit, schema version, result qualifications and immutable checksums. Do not promote historical proof receipts into claims of current-schema or runtime-scanner conformance.

A newly regenerated full-library publication may be linked here only after current-schema validation, source accounting and readable authoring review.
